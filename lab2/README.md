# Описание программы. Анализ данных турнира с выводом отчёта

## Назначение

Программа читает результаты турнира из файла `data.txt`, проверяет каждую запись
на корректность, формирует структуру данных по участникам и предоставляет меню
для просмотра, поиска, анализа и сохранения отчёта в `tournament_report.txt`.

## Формат входных данных

Каждая непустая строка файла описывает одного участника и содержит **6 полей**,
разделённых символом `;`:

```
номер;имя;группа;балл_1;балл_2;балл_3
```

## Проверки входных данных

Для каждой строки выполняются следующие валидации:

- количество полей равно 6;
- номер участника — положительное целое число;
- имя и название группы не пустые;
- все три балла — целые числа в диапазоне от 0 до 100;
- номер участника уникален (нет дубликатов).

Все найденные ошибки собираются в общий список с указанием номера строки.
Строки, содержащие ошибки, исключаются из дальнейшей обработки.

## Расчёт показателей

Для каждого корректного участника вычисляются:

- итоговый балл — сумма трёх баллов;
- средний балл — итог, делённый на 3;
- категория результата:
  - ≥ 240 — «Отличный результат»,
  - 180–239 — «Хороший результат»,
  - 120–179 — «Удовлетворительный результат»,
  - < 120 — «Надо подготовиться».

## Структура отчёта

Файл `tournament_report.txt` содержит 8 разделов:

1. Количество корректных записей.
2. Количество некорректных записей.
3. Перечень уникальных групп.
4. Общий рейтинг участников (по убыванию итогового балла).
5. Список участников, прошедших отбор (итог > 180 и каждый балл > 49).
6. Статистика по группам (средний и максимальный балл, лучшие участники).
7. Общая статистика по баллам (средний, минимальный, максимальный).
8. Список всех ошибок входных данных.

## Интерактивное меню

После загрузки данных пользователю предлагается меню:

1. Показать всех участников.
2. Показать общий рейтинг.
3. Найти участников по группе.
4. Найти участников по части имени.
5. Показать участников, прошедших отбор.
6. Показать статистику по группам.
7. Сохранить отчёт.
0. Завершить программу.

## Итог

Программа представляет собой инструмент **анализа входных данных на ошибки** с
последующим формированием **структурированного отчёта** по результатам турнира.
